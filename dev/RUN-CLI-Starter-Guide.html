RUN CLI Starter Guide

Go from a computer with nothing installed to a deployed RUN.world game. You will install Node.js, Git, the RUN CLI and Claude Code, add the RUN AI skills, then build and ship a game from the terminal.

1

Open a terminal

  1. Press the Windows key and type PowerShell.
  2. Click Windows PowerShell (Windows Terminal also works).
  3. You'll see a prompt like PS C:\Users\You>. Type every command below here, then press Enter.
  1. Press Cmd + Space and type Terminal.
  2. Press Enter.
  3. You'll see a prompt ending in %. Type every command below here, then press Enter.
2

Install Node.js

Node runs your game's dev server and installs its packages. It includes npm. You need version 20 or higher.

  1. Go to nodejs.org/en/download and download the LTS installer for your system.
  2. Run the installer and accept the defaults.
  3. Close and reopen your terminal. A terminal that was already open can't see new installs.

Verify:

node --version
npm --version

node should print v20 or higher. Version 22 or higher is safer, because some RUN features need it.

3

Install Git

Claude Code needs Git on Windows, some RUN features use it, and you'll want it to save your work.

Download it from git-scm.com/download/win and accept the defaults, or run:

winget install Git.Git

Check whether it's already there:

git --version

If Git is missing, macOS offers to install the developer tools. Click Install.

Reopen your terminal, then run git --version to confirm.

4

Install the RUN.world CLI

PowerShell
irm https://github.com/series-ai/rundot-cli-releases/releases/latest/download/install.ps1 | iex
Terminal
curl -fsSL https://github.com/series-ai/rundot-cli-releases/releases/latest/download/install.sh | bash

Close and reopen your terminal, then verify:

rundot --help

You should see a list of commands. If you get "command not found" or "not recognized", restart the terminal again.

5

Install Claude Code

Claude Code is the AI coding assistant that writes and edits your game. It needs a Claude subscription (Pro or Max) or an Anthropic API account.

PowerShell
irm https://claude.ai/install.ps1 | iex
Terminal
curl -fsSL https://claude.ai/install.sh | bash

Or, on either system with Node installed:

npm install -g @anthropic-ai/claude-code

Reopen your terminal and verify with claude --version. The first time you run claude, it opens a browser window so you can log in.

Install commands change over time. If one fails, check the Claude Code docs for the current one.

6

Log in to RUN.world

rundot login

A browser window opens. Sign in with your RUN.world account, then come back to the terminal.

7

Make a project folder

mkdir my-first-game
cd my-first-game

This creates a folder and moves you into it. Stay in it for every step that follows: rundot and claude both act on the folder you're currently in.

8

Install the AI skills

Run this from inside your project folder:

rundot ai setup

It detects which coding agent you use (Claude Code, here) and installs all the RUN skills for it. The skills teach Claude how the RUN SDK works and how to add analytics, ads, saves, shops, notifications, multiplayer and deploys.

Add --yes to skip the confirmation prompts. Re-run the command after updating the CLI to pick up new skills.

9

Start Claude Code in your project

claude

Approve the "trust this folder" prompt. Now you can talk to it in plain English. Some starter prompts:

Scaffold a new RUN game: a simple tap-to-score game, portrait, mobile-first.
What should I work on next?

The rundot-new-game skill sets up a complete project (Vite, Pixi.js, React, and the correct SDK boot order), so you don't assemble anything by hand. The second prompt triggers the rundot-game-coach skill, which suggests your next best move.

Prefer a template? The RUN docs link three: 2D Pixi, 3D React, and a UI-heavy 2D React game.

10

Install dependencies and register the game

Ask Claude to run these for you, or exit it (/exit) and run them yourself:

npm install
rundot init

rundot init asks you to name your game and creates a game.config.prod.json file that holds your game ID and build settings.

11

Test it locally

npm run dev

The terminal prints a local address such as http://localhost:5173. Open it in your browser to play. Press Ctrl + C in the terminal to stop the server.

12

Deploy

npm run build
rundot deploy

You get a shareable link that works on the web or in the RUN.world app. It's unlisted by default, so nobody finds the game unless you share the link.

Common problems

SymptomFix
"command not found" or "not recognized"Close and reopen the terminal. This fixes most cases.
PowerShell blocks the install scriptRun Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, then retry.
Deploy failsRun rundot login again, and make sure you ran rundot init in this folder.
Commands act on the wrong projectRun pwd to see which folder you're in, and cd into your game's folder.

RUN.world CLI commands and the rundot ai setup command were checked against the RUN.world developer docs and the CLI's own help output.
